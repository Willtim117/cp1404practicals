# CP1404 Practicals

This repository contains all the practical exercises for **CP1404 - Programming II** at James Cook University.

## About Me
I am an Engineering student studying at JCU Cairns.
This repo is used to complete and submit the weekly practical tasks for **CP1404**.

## Lessons Learned About Clean Code

Main things I've learned about writing clean code in CP1404:

- Coding is complicated by nature. Therefore, code writing practices are strict.
- Standardization makes it possible to work with the broader community. Everyone is on the same page.
- Work towards the client specifications.
